# AI Travel Video Editor

Скилл для монтажа семейных фильмов и видео из поездок с AI-агентом: каталог исходников, восстановление истории, план сцен, начитка и правки по таймкодам. Общий процесс не привязан к редактору. Платный Resolve не нужен, чтобы начать с планирования или собрать простой немой видеочерновик через FFmpeg.

Актуальная подробная документация — [на английском](README.md): [первый запуск](README.md#start-with-one-scene), [пошаговый тестовый пример](docs/walkthrough.md), [выбор редактора](skills/family-travel-editor/references/editors.md), [заполненный пример](examples/story-to-cut/README.md).

Мой собственный процесс использует Resolve, Photos, почту, Replay и дополнительные модели. Их можно заменить инструментами с аналогичной задачей. Это не означает, что пакет уже умеет автоматически управлять iMovie, CapCut, Shotcut или Kdenlive: для них пока доступны общие планы и инструкции, а нативные интеграции нужно реализовать и проверить отдельно.

В комплекте есть Python-помощники для каталога, проверки окружения, простого FCP 7 XML и немого FFmpeg-превью. Они не собирают весь фильм с речью, музыкой и титрами одной командой. Проверка живого импорта в Resolve остаётся незавершённой. Личные исходники и память фильма хранятся отдельно от установленного скилла.
