# Монтаж видео из путешествий в DaVinci Resolve

**AI-скилл для монтажа видео из путешествий и семейных фильмов в DaVinci Resolve.**

[English](README.md) · [Учебный пример](examples/first-scene/README.md) · [Что проверено](docs/validation.md)

Мы с семьёй путешествуем, я снимаю на DJI Osmo Pocket 3 и дроны. На монтаж поездки у меня обычно уходит 20–30 часов. Работа с агентом пока не показала измеренной экономии времени, но появилась возможность сохранять удачные решения: как восстановить историю, о чём спросить меня, что оставить в сцене и как проверить результат.

Family Travel Editor — переносимый скилл для Codex и совместимых локальных агентов: разбор видео с камеры и дрона, план истории, текст закадровой начитки и монтаж по комментариям с таймкодами. В комплекте небольшие помощники и экспериментальный пакет плагина для локальной работы.

![Процесс монтажа](docs/workflow.png)

Схема показывает исходный авторский процесс. Указанные сервисы и аудиомодели — дополнительные возможности, они не входят в установку.

## Начать

```sh
git clone https://github.com/denyakortunov/family-travel-editor.git
cd family-travel-editor
python3 skills/family-travel-editor/scripts/project.py doctor
```

Откройте папку в локальном агенте и напишите:

> Прочитай skills/family-travel-editor/SKILL.md. Исходники находятся в [папка]. Помоги выбрать и спланировать одну сцену. Спрашивай о воспоминаниях там, где они влияют на историю. Сохрани исходники и сначала проверь доступные инструменты.

Для установки в каталог навыков Codex:

```sh
python3 tools/install_skill.py --destination ~/.codex/skills
```

Установщик не заменяет существующий навык. Если клиент использует другой каталог, передайте его через --destination. После установки начните новый чат и вызовите `$family-travel-editor`.

## Что есть в первом выпуске

Правила восстановления контекста, выбора кадров, начитки, монтажа, проверки результата и работы с комментариями. Пустые шаблоны памяти проекта. Помощники для каталога, измерений экспорта, соединения с Resolve и простого монтажного XML. Синтетический пример показывает изменение длины сцены по замечанию.

Версия 0.1.1 экспериментальная. XML-помощник поддерживает только видео, простые склейки и одинаковую целую частоту 24/25/30 fps; звук, титры и эффекты он не переносит. Живой импорт в Resolve при подготовке выпуска проверить не удалось. Проверенные функции и ограничения перечислены в [отчёте](docs/validation.md).

Для скриптов нужен Python 3.9+, для примера и измерений — FFmpeg. ffprobe добавляет технические метаданные. Нативный монтаж ориентирован на Resolve Studio на macOS. Фото, почта, Replay и дополнительные модели необязательны: их можно заменить вопросами, выбранными файлами и текстовыми таймкодами.

Личные воспоминания, исходники и комментарии хранятся отдельно от установленного скилла. Этот пакет сам не подключает почту, не загружает медиа и не публикует фильмы.
