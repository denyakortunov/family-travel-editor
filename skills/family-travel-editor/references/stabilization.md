# Stabilization without losing the shot

Select a coherent useful movement phase first. Stabilization can reduce shake but cannot repair an unfinished reveal, an unintended reversal or poor composition. Keep the original and process a separate derivative with handles around the chosen range; preserve speed, source time mapping and original audio.

Before gyro-based processing, inspect the actual file for compatible motion telemetry, lens calibration and timing/readout information. Brand or model names do not prove that this particular recording contains them. If the required data is absent, report that limit and evaluate an available optical/editor stabilization route on a separate sample; do not label it gyro stabilization.

Try one representative range before processing a batch. Compare before/after in motion for horizon behaviour, edge crop, wobble, distorted geometry, rolling-shutter artifacts and retained camera intent. Check parameter units and ranges in the installed version instead of guessing from names. Horizon lock strength is a choice for that shot, not a mandatory maximum setting.

Verify frame rate, duration, selected source range and relinked media in the editor. Then check colour through the source-to-export chain using [colour and titles](colour-and-titles.md). A technically valid stabilization output does not close an unresolved colour or composition issue.

Native editor stabilization and external tools such as Gyroflow are optional, separately installed workflows. This skill does not bundle a stabilizer, telemetry parser or universal camera preset. Preserve project/settings and input/output identities for the selected trial; omit device serial numbers from shared reports.
