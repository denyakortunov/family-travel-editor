# What’s New in v0.3.4

29 October 2026 — show the work and the result.

## Changed

- Replaced the photographic concept cover with an original vector diagram: three source clips, selected ranges, a scene plan and a specific revision.
- Rebuilt the workflow around a concrete example. A 22-second scene becomes 20 seconds by trimming the final shot; the preceding shots and both versions are kept. The timings are illustrative, not a new rendered demonstration.
- Used one sans-serif type system, aligned columns, clear labels and spaced connectors. The mobile diagram stacks the same steps vertically.
- Updated the skill icon and social-sharing image to match the diagrams. The source SVGs remain editable.
- Removed the generated travel cover from the current download. Previous tagged releases remain unchanged.

## Capabilities

This release changes presentation, not editing capabilities. It is an AI agent skill, not a standalone video editor. Full assembly happens in your editor; native automation needs a separately available, tested integration. Bundled helper previews remain silent. The existing real-footage example is unchanged.

## Updating

Download v0.3.4 and run the supplied installer with `--update` against your existing skills directory. The installer backs up the previous installation and leaves film workspaces alone. Run the printed installation check and open a fresh chat.
