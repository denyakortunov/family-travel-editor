# What’s New in v0.3.5

29 October 2026 — a simpler explanation of the skill.

- The introduction now says directly what this is: an AI skill for Claude Code and Codex that helps you put together your travel videos.
- A simple illustration shows separate travel clips becoming one filmstrip. It replaces the interface-like cards, tables, timecodes and abstract headlines.
- The README has one introductory illustration, with a vertical version for phones. The full workflow guide uses the same visual language.
- Updated the social-sharing cover and filmstrip icon. All illustrations are original, editable vectors; there are no generated photographs.

This is a presentation update. The skill helps you work in your video editor; it is not a standalone editor. Bundled preview helpers remain silent, and native editor automation still needs an available, tested integration. Claude Code filesystem installation and a practical Claude exercise have been checked; this does not claim a tested installation in the Claude website chat.
