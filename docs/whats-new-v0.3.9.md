# What’s New in v0.3.9

2 November 2026 — preserve the sound you intended.

This update brings practical lessons from recent editing into the skill: how to check an automated mix, replace music without losing its treatment, and make an object sound land on the action. It also adds an optional music-library guide and fixes first-use version instructions.

## Added

- **Fairlight review procedure.** Work in a copy, preserve the intended musical rises and pauses, compare clips by source and time after track regrouping, and check the rendered sound. A louder export is not necessarily a better mix.
- **Music replacement after automixing.** Check track/bus automation as well as clip properties; export and compare the affected scene before accepting the replacement.
- **Object-sound sync.** Match the picture contact to the audible attack inside the sound file, then check where it lands in the export. Review neighboring speech, music and effects after a change.
- **Optional Epidemic Sound recipe.** Reference-based discovery, candidate listening, downloads, license records and the limits of track adaptation. Use your own connection and subscription where required; no library is required to start with the skill.

## Improved

- New sound references are linked from the skill and the relevant editing/checking guides, so the agent loads them when needed.
- Downloads, pinned installation commands and the expected installation-check version now agree on v0.3.9. Updating preserves the previous installed copy and leaves film workspaces separate.
- This release's notes use absolute, versioned documentation links so they work on the GitHub release page as well as in the repository.
- The roadmap identifies the existing Shotcut draft and the desktop checks still needed before it can ship.
- Release checks use Ubuntu 24.04 explicitly, preserving the Python 3.9 test after GitHub's default runner moved to Ubuntu 26.04.

## Compatibility and limits

This is an instruction and documentation update. No helper programs or existing features were removed; no new editor automation is bundled. The preview remains silent and XML remains video-only. Resolve's bundled native import/playback/export is still unvalidated; the Shotcut draft is excluded. Fairlight guidance comes from a production trial, not a certification of the public adapter. Installation tests do not prove listening quality or a finished film.
