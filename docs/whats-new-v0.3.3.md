# What’s New in v0.3.3

29 October 2026 — a clearer visual introduction.

## Improved

- A photographic editorial cover replaces the old camera illustration for social sharing; the README now uses the same visual identity.
- New editable desktop and mobile workflow diagrams use clear type, generous spacing and a separate review loop. Arrowheads no longer collide with each other or the content.
- Five stages explain the journey from footage and memories to a reviewed film and saved context. Current diagrams no longer name obsolete review services.
- A coordinated frame-and-landscape icon and deep green accent bring the skill listing into the same visual family.
- The full workflow page includes the updated diagram and a repaired tools-and-costs link.

## Unchanged capabilities

This is a visual and documentation update. It remains an AI agent skill, not a standalone video editor. Native editing needs a separately available, tested connection. The bundled preview remains silent; this release does not add audio mixing or certify editor integrations. Cover images are AI-generated concepts, not footage from a user's film.

## Updating

Download the v0.3.3 source ZIP and run the supplied installer with `--update` against your existing skills directory. Your previous installation is backed up. Film workspaces are not replaced. Run the installation check printed by the installer and open a fresh chat.
