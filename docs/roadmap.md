# Roadmap

The aim is a repeatable first scene, then an editable film. Items below are plans, not shipped capabilities.

1. Validate the existing XML adapter in a clean native Resolve project: import, playback, export and source relinking, with version/platform evidence.
2. Complete Shotcut desktop open/edit/save verification for the experimental MLT adapter, in addition to the command-line render tests. Keep editor-specific metadata out of the shared story plan.
3. Extend the plan and tests for audio, mixed frame rates and transitions before claiming full scene assembly.
4. Add an independently reproduced real-footage walkthrough, with redistribution rights and clear human/agent responsibilities.

Useful contributions: a native round-trip report; a small failing fixture; a tested adapter; clearer first-run instructions. Open an issue describing the result you can demonstrate before building a large integration.
