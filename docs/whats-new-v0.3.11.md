# What's New in v0.3.11

4 November 2026

- Added a CapCut Web route using the optional official Codex plugin, including connection, a first-scene prompt and continuing an existing cloud project.

This release updates instructions and compatibility documentation. CapCut, its plugin, accounts and usage allowances are separate; helper commands are unchanged.
