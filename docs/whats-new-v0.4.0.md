# What's New in v0.4.0

17 November 2026

This release brings editing lessons from recent film work into the reusable skill. It improves how the agent plans, reviews and revises a film; the bundled helper programs are unchanged.

- **Scenes that belong to the same film.** Check chapter order, unresolved events, callbacks and meaningful endings. Preserve a joke's setup and reaction, and distinguish calmer individual shots from removing an entire musical sequence.
- **Transitions checked in the rendered picture.** Review the dominant camera gesture on both sides, including depth and vertical motion. Track landmarks through the effect itself, compare a straight cut and retain complete spatial reveals.
- **Smoother sound joins and steadier music.** Choose overlaps for the actual ambience, protect whole speech episodes and inspect the rendered mix. Diagnose quiet source passages and overlapping ducking that can unexpectedly bury a music bed.
- **Colour and stabilization reviewed separately.** Trace original footage through stabilized/transcoded copies to the export, check profiles and transforms, and match neighbouring shots. Verify actual telemetry before gyro stabilization; keep originals and test a representative range first.
- **Titles and route maps with a purpose.** Check meaning, language, timing and readability as well as design. Keep departure, journey and arrival cues in a coherent order.
- **A practical voiceover packet.** Prepare text, placement, timing and scene context together; check the recording input, track and destination before a take, then fit the edit and music around the accepted recording.
- **More reliable Resolve verification and project memory.** Recheck incomplete API snapshots in the correct timeline/page context, compare nested fades with archived evidence and previous exports, and reopen findings contradicted by user feedback. Store feedback in the existing workspace collection and keep public procedures free of private project details.

The documentation now routes these tasks to focused references. The existing first-run interview, saved brief, helper interfaces and workspace formats remain compatible; no workspace migration is needed.
